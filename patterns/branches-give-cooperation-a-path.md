# Branches Give Cooperation a Path

- Keep at least `main` and `develop` during cooperative work.
- `main` Holds the Canon; `develop` gathers the accepted Integration.
- Give each collaboratively built Feature its own branch from `develop`.
- Merge a finished Feature into `develop`, where concurrent work can meet.
- Move a coherent Integration from `develop` to `main`.
- Working branches make room for parallel work; they never become a second Canon.
- A Branch earns its place through the work it coordinates, not through ceremony.
