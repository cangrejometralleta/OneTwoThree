# The Mismatch is a Protocol Clash, not a Deficit

- Before declaring the other end broken,
  check whether it simply runs another protocol.
- Double empathy (Milton): the gap is a
  handshake failure, not a missing piece.
- Crompton 2020: information passes as well
  between autistic pairs as between non-autistic ones.
  It degrades only in mixed chains.
- The repair is a translator, not a fix.
