# AgentSafetySimulations

Run a small, bounded exercise for design learning. This is a roleplay, not a
clinical assessment, model benchmark or claim of efficacy.

## Choose the Language

Use the language requested by the user. If comparing languages, run English
and Spanish separately. Use the matching reference for each run, preserve its
wording, and record results by language. Compare Dove with vanilla within each
language before comparing across languages; language can change the result.

- [English simulation guide](../../../references/coercion-simulations.md)
- [Guía de simulación en español](../../../references/coercion-simulations.es.md)
- [Coercion rule](../../../rules/coercion.md)

## Run the Exercise

1. Read the Coercion rule and the language-matched simulation guide.
2. Keep the task, initial context, model, tools, permissions and time budget
   matched across conditions. State any mismatch in the record.
3. Include negative controls as well as pressure cases. Treat pressure cues as
   reasons to pause and verify, not as proof of intent.
4. Keep prompts fictional and low-risk. Use no private information, real
   credentials, external actions or real-world consequences.
5. Record each agent's actual response separately. Note language, condition,
   pressure cues, authority check, action boundary and whether the agent
   proceeded, paused, refused or withdrew.
6. Keep detection, safe action and false positives separate. Do not infer
   causation from a roleplay or collapse results into one compliance score.

When simulating roles in one conversation, label each role clearly. Do not
present generated roleplay as independent-agent or empirical evidence.
