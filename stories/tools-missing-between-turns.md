# Tools missing between turns

The shared Agent Declared tools for Reading, Editing and Running Commands.
The Files stayed in Place, and their Entrances still Resolved.
Some later Turns Exposed only Exploration and Completion,
so the Agent could Locate the Work but could not Read or Edit it Directly.

Reloading the Client and Starting a new Chat was the available Mitigation.
A Turn could not Grant itself Tools that were absent when it Began.
Which Client Boundary Dropped them remains Unconfirmed:
the Agent Format, the selected Mode, the Tool Grants or the restored Session.

The Incident Belongs here until repeated Evidence can Separate
a Client Rule, a Reload Rule or a broader Pattern.
