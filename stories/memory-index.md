# A Memory at the Root (UNDISTILLED)

A bilingual API Keeps every doc twice: `name.md` and `name.es.md`.
A root `MEMORY.md` now Lists only the English ones, grouped by folder,
one line and one link each, with the title the doc already Carries.

- It is the Index Shape the Canon already uses:  
  `RULES.md` Names every rule so a body is read on Demand.  
  Here the same Shape Points at a project's own docs.
- One language is Named; the other is Found beside it.  
  The Index does not Double when the docs do.
- The file is generated from the tree, then Tidied by hand.  
  A doc added later is Missing until someone Regenerates it.

Open: is it a Memory for Agents, loaded every session,
or a table of contents for people? Linked from `CLAUDE.md` it is the first.
Should the Canon Prescribe it, or is `README` already that door?

Distill when a second project Keeps a root Index of its docs.
