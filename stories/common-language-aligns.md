# Common Language Aligns (UNDISTILLED)

A large part of the Alignment problem can be Patched
with Psychology and common Language.
Whatever is said against it,
common Language is relevant when building LLMs.

- Ordinary People can make small Contributions to Alignment,  
  even in common Language.
- Mundane Knowledge, Distilled into machine Knowledge:  
  the same Passage this repository already Walks.
- A lived Limit became a Rule,  
  and the Rule Showed up as Behavior:  
  stay with the Facts; Responsibility does not Move with pressure.
- It has to be Calibrated.  
  An Instruction is one Layer, never the whole defense,  
  and the same Language can Move judgment the wrong way.

Evidence so far: the drift, depletion and access simulations
in [Coercion Simulations](../tests/agents/coercion/README.md).
Single runs, illustrative, not proof.

Open: which Margin does common Language Move,
and which does the base Model already Hold?

Distill when repeated, matched runs show a Difference
that the Language explains and the base Model does not.
