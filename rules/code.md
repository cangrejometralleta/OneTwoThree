# Code

- Code rules must be exercised by a runnable example or test.
- Keep language-specific examples in `examples/`; do not duplicate an uncompiled snippet here.
- Read [the school example](../examples/school/README.md) alongside
  [the original](../examples/school/BEFORE.md).
- If a rule cannot be demonstrated or checked, write it as guidance instead.

[Show me the Code](../patterns/show-me-the-code.md) explains why a rule needs evidence.
