# The Head is the Canon

- The Canon is the Head of `main`, and nothing else.
  A tag or release is a named snapshot for distribution, never a second Canon.
- `1.0.0` remains the UNTAG: a record of the practice this repository ended.
  `v1.0.0` is the first stable release of the work that followed.
- A release records a useful state; it does not declare the work finished.
  `main` continues to move and remains the source of current truth.
- A project that pins a release follows that snapshot as a Fork.
  That is Allowed, and it must be said out loud.
- A Rule is true until a Commit Replaces it.  
  The Replacement is the Announcement.
- Read the Head before you quote a rule.  
  A rule read last month may have Lost its argument since.
- Ask what `origin/main` says, never what a local copy Remembers.  
  The Copy is a Cache; the Head is the Claim.
