# Channels

- Check which visual channels the target surface supports before using them.
- Give each channel one meaning. For example: bold marks emphasis, a quote marks an aside, and strikethrough marks deletion.
- Use whitespace to separate groups.
- Check the rendered result; HTML and terminal escape sequences may not survive.
- If the surface cannot carry everything clearly, cut content instead of adding more marks.
- Never encode meaning in a key that code compares. See [Emoji](emoji.md).
