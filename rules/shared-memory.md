# Shared Memory

- Create project Memory in one shared Source that every Agent working in the
  repository can read and maintain within its permissions.
- Never keep the only Copy in an agent-specific Memory store, profile or
  workspace.
- When a new, reusable Workflow is discovered while working in another
  repository, document it in that same repository's shared Memory after its
  first useful execution. Record its trigger, essential Steps and verification
  so every Agent there can repeat it. Do not move that lesson into this Canon.
- Keep private preferences and runtime state out of shared project Memory.
- Link the shared Source from the project's existing instruction or context
  index so every Agent can find it.
