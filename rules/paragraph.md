# Paragraph

- Give each paragraph one claim and state it first.
- Make headings state the claim, not just the topic.
- Read the first line of each paragraph as an outline. Revise if the outline misses the argument.
- Delete sentences that only repeat the opening claim.
- Use three to five sentences as a guide, not a limit. Split when a new claim begins.
- Use structure to navigate long documents; use emphasis only to mark priority.
- A script can find repeated wording. A reader decides whether the ideas belong together.
